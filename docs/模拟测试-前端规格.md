## 数据接口

前端需要从两个新 JSON 文件读数据：

### 1. `data/exams.json` — 真题库

```json
[
  {
    "school": "人大",
    "year": 2025,
    "title": "2025年人大845社会学理论真题",
    "subject": "theory",
    "duration": 180,
    "totalScore": 150,
    "questions": [
      {
        "type": "名词解释",
        "number": 1,
        "question": "社会整合",
        "score": 5,
        "conceptId": "c_xxx"
      }
    ]
  }
]
```

### 2. `data/schools.json` — 学校配置

```json
{
  "schools": [
    {"id": "ruc", "name": "人大", "fullName": "中国人民大学", "level": "985"},
    {"id": "nju", "name": "南大", "fullName": "南京大学", "level": "985"},
    ...
  ]
}
```

## JS 逻辑

新的全局状态：

```js
var examMode = 'auto'; // 'auto' | 'real'
var examSchool = 'ruc'; // 学校ID
var examYear = 2025;    // 真题年份
```

`startMockExam()` 改为两个分支：
- `examMode === 'auto'` → 调 `generateAIExam(school, count, types, difficulty)` → DeepSeek 出题
- `examMode === 'real'` → 从 `exams.json` 查对应学校+年份的真题 → 直接渲染

考试界面、计时、批改全部复用现有 `examSession` / `evaluateWithAI`。

## 样式

新面板用已有的 `.panel` 和 `.sub-panel` 样式体系。学校选择器可以用简单 `<select>` 或做成卡片选择（类似现有 subj-card）。
