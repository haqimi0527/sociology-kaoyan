# concepts.json 数据质量问题清单

> 扫描日期：2026-07-14
> 总概念数：2,418 条
> 给后端/数据组看的，按严重程度排

## 🔴 P0 — 阻塞性问题（渲染出来是垃圾，前端救不了）

### 1. 概念名是句子片段（84 条）

概念名应该是"异化""科层制"这种词，但有一些是完整句子。前端当标题显示时就是一大坨。

| 示例 ID | 概念名 |
|----------|--------|
| experiment | 书则进一步将实验（experiment） |
| — | 用常人方法学的观点分析日常生活的实践活动并举例说明 |
| — | 劳动分工与个人自由：马克思、涂尔于、韦伯对比 |
| — | 知识社会学视野：涂尔干、米德、舍勒与曼海姆 |

**修法**：把句子里真正的概念词提取出来作为 term，原句子移到 `definition` 或删掉。

### 2. 概念名含编号前缀（34 条）

| 示例 |
|------|
| （1）导致社会变迁的基本动力 |
| 1）主观意义与客观意义 |
| 344.由角色距离理论得出的结论 |

**修法**：去掉编号前缀。

### 3. 定义以冒号开头（27 条）

定义字段第一个字符就是 `：` 或 `:`，说明数据提取时没清理干净。

| 概念名 | 定义开头 |
|--------|----------|
| 书则进一步将实验（experiment） | ：一种经过精心的设计… |
| 概念工具常常面临两种困境 | ：或是由于概念过于宽泛… |

**修法**：trim 掉开头冒号。

### 4. 定义混入脚注/参考文献标记（100 条）

| 概念名 | 混入的内容 |
|--------|-----------|
| 书则进一步将实验 | …①TheEncyclopediaofSociology.DPGReferencePublishingInc.，1981:179 |
| 代差 | …①是社会发展过程中的正常现象 |
| 角色集 | …①多种 |

**修法**：正则去掉 `① ② ③` 标记及后面的参考文献字符串。

### 5. Chapter 分类错误

| 概念 | 当前 chapter | 应该是 |
|------|-------------|--------|
| 书则进一步将实验（experiment） | 方法/抽样133/ | 方法/实验法/ |
| 可行性（feasibility） | 方法/。/ | 方法/基础概念/ |
| 分析单位（unitofanalysis） | 方法/。/ | 方法/基础概念/ |

## 🟠 P1 — 严重影响体验

### 6. core_points 和 definition 高度重复（2,156 条，89%）

几乎每一条概念的 `core_points[0]` 都是 `definition` 的截断或完全重复。这导致前端展示时——概念详情面板的"定义"和"核心要点"两栏内容一样，用户看着就是废话。

**修法**：core_points 应该是对定义的提炼（关键词、对比维度、记忆口诀），而不是复制粘贴。

### 7. ID 格式不统一（340 条非 `c_` 前缀）

| ID 前缀 | 数量 | 示例 |
|---------|------|------|
| `lcwiki_` | 261 | lcwiki_异化、lcwiki_失范 |
| 英文单词 | ~79 | experiment、feasibility、theory |

**影响**：`conceptIndex` 用 c.id 做索引，同一条概念可能在 lcwiki_xxx 和 c_xxx 里各有一条。关联概念的 `related[].id` 指向 `c_` 前缀时，lcwiki 概念查不到（反之亦然）。

**修法**：统一 ID 生成规则，全部改为 `c_` 前缀或全部改为英文 slug。保一留一。

### 8. related 字段格式不统一（142 条用纯字符串数组）

正常格式：
```json
"related": [{ "id": "c_xxx", "relation": "parallel" }]
```

lcwiki 概念的格式：
```json
"related": ["商品拜物教", "虚假意识", "物化"]
```

纯字符串没有 `relation` 类型，也没有 `id` 可查询——你都不知道它是指哪个具体概念。

**修法**：统一为 `{ "id": "c_xxx", "relation": "..." }` 格式。

## 🟡 P2 — 影响展示质量

### 9. 定义过长（67 条，最长 8,052 字）

| 概念名 | 定义长度 |
|--------|---------|
| 《儒教与道教》 | 8,052 字 |
| 社会几何学 | 7,243 字 |
| 生活世界与系统 | 580 字 |

超过 500 字的定义大概率是把整段教材原文塞进去了，不适合做闪卡。

**修法**：定义控制在 200 字以内，超出部分放到 `core_points` 或删掉。

### 10. 概念名含括号（86 条）

| 示例 |
|------|
| 书则进一步将实验（experiment） |
| 可行性（feasibility） |
| 分析单位（unitofanalysis） |

括号里的英文是 OCR 残留或翻译备注，不是概念名的一部分。

**修法**：去掉 `（英文）` 后缀，或改为 `name_en` 独立字段。

### 11. 概念名含书名号（若干）

| 示例 |
|------|
| 《儒教与道教》 |
| 《新教伦理与资本主义精神》 |
| 《货币哲学》- |

这些是著作名称，不是社会学概念。

**修法**：如果是介绍该书的条目，概念名改为"儒教与道教（著作）"或拆成独立字段。

### 12. core_points 混入脚注（121 条）

同问题 4，定义里有的脚注在 core_points 里也会出现。
