## 二、今日教训与错误（最重要，给前端的理解上下文）

### 错误 1：verify "全绿" 是假象，WARN 被淹没
**现象**：自检系统跑 verify 显示 PASS，但数据问题一大堆（proponent 错位 118 条、章节错位等全被 WARN 淹没）。
**根因**：verify.sh 只看退出码，WARN 永不失败；几百条 WARN 混在 stdout 无分级无出口。
**修复**：升级为 audit_runner 统一出口，退出码三态 `0真PASS / 1FAIL / 2REVIEW(blocker WARN 须人审)`。
**教训**：**"全绿"不等于"没问题"**。任何数据校验必须分级，blocker 级问题必须人审，不能只看退出码。

### 错误 2：中文编辑距离检测严重误报
**现象**：E2 编辑距离 ratio≥0.8 检出 106 条变体候选，但几乎全是「标准~标准差」「文明化~文明」这类词根派生，是独立考点不是重复。
**根因**：中文词根派生天然高相似，0.8 阈值对中文根本不适用。
**修复**：E2 降级 INFO 参考；E1 定义相似（前80字 difflib）才是真变体强信号。
**教训**：**检测阈值不能套用英文/通用经验，中文要用中文校准**。数据校验的误报和漏报一样有害。

### 错误 3：term 不同 + 定义不同的变体重复，纯查重抓不到
**现象**：「资本主义的文化悲剧」vs「文化悲剧」是同一概念，但 term 不同、定义也不同（一个被污染），现有 term 查重和定义查重都抓不到。
**根因**：变体检测脚本（08-01 的一次性脚本）没固化进 verify.sh，日常自检根本不扫变体重复。
**修复**：新增 Layer E 变体检测（定义相似/编辑距离/归一精确/别名引用/共享词），含"修饰前缀变体"（`X的Y` 去前缀后比对）。
**教训**：**"term 不同但同一概念"是最隐蔽的重复**，必须靠变体检测全量扫，且检测能力要固化进自检系统，不能靠人工发现。

### 错误 4：JSON 值内 ASCII 引号导致整个文件报废
**现象**：essay-answers.json 因值内未转义 ASCII 引号（`"策略生成的母体"` 等）整个文件无法解析，5 篇范文全崩，App 加载即崩。
**修复**：状态机修复（字符串结束判断要含 `:` 键名场景），替换为全角中文引号。
**教训**：**中文 JSON 里出现 ASCII 引号会炸解析**。数据写入必须校验 JSON 可解析性。

### 错误 5：politics 选项合并损坏 + 答案越界
**现象**：113 题选项里被吞进 `B．`/`C．`/`D．` 标签（`联系的条件性B．度的关节点C．主要矛盾` 是 3 个选项被压缩），导致答案越界、做题崩。
**修复**：按 `[A-D][．.、]` 标签拆分（111 题修复），7 题整题拼接标人工。
**教训**：**OCR/数据合并时选项标签会串进内容**。题库数据必须校验"选项数 + 答案索引"一致性。

### 错误 6：proponent/归属判断不能凭印象
**现象**：「资本主义的文化悲剧」我曾判断归韦伯，实际是**齐美尔**（《货币哲学》文化悲剧）；「选择性亲和关系」我猜韦伯，教材原文证实是**鲍曼**。
**修复**：社会学归属拿不准 → 查教材原文或 DeepSeek 判定，绝不凭记忆改。
**教训**：**社会学判断必须查证原文**，这已成为 concept-dict-quality skill 的纪律第 8 条。

### 错误 7：era 映射表方向写反
**现象**：era_short_to_full 映射方向写反，导致 era_mismatch 误报 591 条（全是假的）。
**修复**：修正映射方向，era_mismatch 收敛到 15 条真错位。
**教训**：**映射表方向必须核对**，用已知对 dry-run 验证。

## 四、前端需要知道的

### 数据结构变化（可能影响前端渲染）
1. **taxonomy 新增 `ungrouped_concepts` 桶**——学派直挂的概念（如"冲突理论"下 38 条没细分到学者的），现在在 taxonomy 的学派节点下有 `ungrouped_concepts` 数组。前端渲染 taxonomy 时如果只遍历 `scholars`，这些概念会"消失"。已适配（index.html 加了"（未分学者）"桶），确认前端逻辑。

2. **exams.json subject 统一**——`method` 值已全部改成 `methods`。前端如果按 subject 过滤，注意只用 `methods`。

3. **exams.json 删了 278 条占位题**（南大198+武大66）——这些是"略/题目原文缺失/?????"，本来就没内容，删了不影响。

4. **politics.json 选项结构修复**——111 题选项从合并损坏恢复到正常 4 项。前端做题逻辑不受影响，但注意 22 条标人工的题（pol_41/pol_964 等）选项可能仍异常，如遇请标记。

- **exam-engine.js 依赖 DeepSeek 生成答案**（exams.json 本身无 answer 字段）——真题刷题的答案由运行时生成，前端已验证（Playwright 6/6）。
