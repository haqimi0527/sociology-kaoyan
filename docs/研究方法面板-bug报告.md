# 研究方法面板 bug 报告

## 三个问题

### 1. 点击子分类不渲染概念卡片（严重）

**复现**：研究方法面板 → 左侧点"研究设计" → 右侧出现子分类（测量与操作化74、研究类型58、选题与文献6）→ 点"测量与操作化" → **下方没有出现概念卡片列表**。

**原因**：子分类的点击事件没接上 `renderMetCards()`。理论和方法的分类浏览器应该各自调用各自的概念渲染函数：
- 理论面板 → 点分类 → `renderThrConceptList()`
- 方法面板 → 点分类 → `renderMetCards()`（这个函数已经有了，只是没被调用）

### 2. 左侧栏文案没适配（中等）

方法面板的分类浏览器左侧标题写的是"时期/阶段"和"📦 全部时期"——这是理论面板的文案，直接复用了。

应该改成：
- "时期/阶段" → "研究阶段"
- "📦 全部时期" → "📦 全部模块"

### 3. 底部 tag 标签冗余（轻微）

筛选结果下方的 tag 标签把所有方法的标签全部摊开了（定量、定性、描述统计、测量与操作化、研究类型……混在一起），没有和当前选中的分类联动。

---

## 数据结构参考

方法概念的 `chapter` 路径格式：`社会学研究方法/{阶段}/{子分类}/`

例如：`社会学研究方法/研究设计/测量与操作化/`

所以两级联动逻辑是：
1. 左侧"阶段"：去重 `chapter` 的第一级（研究设计、抽样、资料收集、资料分析、研究基础）
2. 右侧"子分类"：选中阶段后，去重该阶段下的第二级
3. 选中子分类后，`concepts.filter(c => c.chapter.indexOf('社会学研究方法/研究设计/测量与操作化/') === 0)` 过滤出概念，传给 `renderMetCards()`
