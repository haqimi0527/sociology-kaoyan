## tags 字段（新增）

每个概念都有 `tags` 数组，用于交叉筛选：

```json
{
  "term": "理想类型",
  "chapter": "理论/古典时期/韦伯/",
  "tags": ["古典时期", "韦伯", "方法论概念"]
}
```

tag 值包括：
- **理论维度**：古典时期、现代时期、当代时期、功能论、冲突论、符号互动论、交换论、现象学、批判理论、后现代、后结构、结构化理论、实践理论、理性选择、过程社会学、方法论概念
- **方法维度**：研究基础、研究设计、抽样、资料收集、资料分析、定量、定性、描述统计、推断统计、多元统计

## 前端分类浏览器逻辑

两级联动：
1. **左侧栏**：按 chapter 第一级去重列出（理论的是"时期"，方法的是"阶段"）
2. **右侧栏**：选中左侧项后，按 chapter 第二级去重列出（理论的是"理论家/流派"，方法的是"子分类"）
3. **选中子分类**：`concepts.filter(c => c.chapter.indexOf(选中路径) === 0)` 过滤出概念
4. **tag 交叉筛选**：在已过滤的概念中，按选中的 tags 进一步 AND 过滤
