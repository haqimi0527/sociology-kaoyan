## 一、概念名是 OCR/文本碎片（应删除或合并）

这些不是独立概念，是 textbook 提取时句子碎片被误标。约 20-30 条：

```
反的路线、自已的说法、"停在表面"、……模仿空无、责任"、
韦伯认为社会行动、自由同等法、自由社会制度、精神危机、
研究、答案输出、涉及人群、调整机制、资产阶级采取的办法、
逻辑/过程、革命领导权、一样是以事实、功能论的范式之下
```

**修法**：直接删除，或合并到上层概念。

---

## 二、定义截断——缺主语开头（最多，约 100+ 条）

定义以"是""是指""是由"开头，丢了主语。典型：

```
集体表象   → "是涂尔干为了弥补集体意识概念的空泛而提出的…"
社会资本   → "是布迪厄提出的四种资本类型之一…"
谈话分析   → "是由加芬克尔等人创立的经验研究方法…"
方法论置括号 → "是吉登斯在论述行动理论和制度理论时所运用的…"
```

**修法**：批量在定义前补 `term`，变成 `"集体表象是涂尔干为了弥补…"`。

---

## 三、定义残缺——前半句丢失（约 30 条）

```
文化相对主义 → "所赖以生存的环境看，每一种文化模式…"（缺主语从句）
过渡性贫困   → "正常的社会生活。这种在特定时期内…"（缺前半句）
自然差别     → "传机制方面存在的各种差异…"（"遗"字断了）
相对贫困     → "以使其达到一个社会的平均生活水平…"（缺"难"字）
```

**修法**：回原始 textbook OCR 文本找完整句子补上。

## 四、建议加 compile 过滤规则

以下特征的概念直接拒绝入库或标记人工审核：

| 规则 | 示例 |
|------|------|
| 概念名长度 < 3 或 > 25 | `研究`(1字)、`韦伯认为社会行动`(8字但明显是句子) |
| 概念名含标点符号 | `"停在表面"`、`……模仿空无`、`责任"` |
| 概念名以虚词开头 | `自已的说法`、`反的路线` |
| 定义以"的是""是指"等指代开头 | 缺主语，说明原文截断 |
| 定义长度 < 10 字符 | 内容残缺 |
