### 3. 实现细节

- **两级联动**：左边选时期，右边联动显示该时期下的理论家/流派及数量
- **tag 筛选**：点击 tag 可添加/移除筛选条件，支持多 tag AND 逻辑
- **搜索结果**：搜索框输入时切换到搜索结果视图，清空时回到分类浏览
- **响应式**：左侧分类列表在窄屏改为下拉选择
- **数量实时更新**：分类名后的数字基于实际过滤结果

### 4. 改动的函数

- `searchConceptsShell()` → 增加无搜索词时显示分类浏览器
- 新增 `renderCategoryBrowser(concepts)` → 渲染分类树
- 新增 `renderTagFilters(activeTags)` → 渲染 tag 筛选栏
- 新增 `filterByTags(concepts, tags)` → tag 交叉过滤
- `conceptRow(c)` → 卡片上显示 tag 小标签

### 5. 页面位置

理论面板在 `#sub-thr-concept` (当前 `index.html` ~L1294)
方法面板在 `#panel-methods` (~L1455)
两个面板各自独立渲染各自的分类浏览器。

### 6. 向后兼容

- `isTheoryConcept()` / `isMethodsConcept()` 保持不变
- `conceptRow()` 增加的 tag 显示是可选的（没有 tags 字段也不报错）
- 现有搜索功能继续工作
