# 社会学考研知识库 · 概念分类体系说明

> 📅 2026-08-02 | 数据源：`web/data/concept-taxonomy.json`（1968 概念，全部分类，unclassified 0）
> 用途：前端分类浏览器 / 概念树渲染的**权威依据**，前端按此结构读取展示

---

## 一、整体结构（三大域）

```
concept-taxonomy.json
├── theory   理论域（1068 概念）—— 时期 → 学派 → 学者 → 概念
├── methods  方法域（556 概念） —— 阶段 → 类目 → 概念
└── intro    概论域（344 概念） —— 主题 → 概念
```

**数据契约**：
- 概念 ID 以 `c_`（原始）或 `lc_`（lcwiki）开头，存于各节点 `concepts` 数组
- 学派直挂但未细分到学者的概念，存于学派节点 `ungrouped_concepts` 数组（**前端必须渲染**）
- `chapter` 字段（concepts.json 内）与 taxonomy 结构对应，规范格式见下

---

## 二、chapter 字段规范（concepts.json）

```
理论：理论/<时期>/<学派>/<学者>/
方法：方法/<阶段>/<类目>/
概论：概论/<主题>/
```

**时期取值**（theory 域）：
`古典时期` / `现代时期` / `当代时期` / `综合与比较`

**时期在 taxonomy 键名带括号副标**（前端展示可去掉括号取主名）：
`古典时期 (1830s-1920s)` / `现代时期 (1930s-1970s)` / `当代时期 (1980s-)` / `综合与比较`

## 六、前端渲染要点（⚠️ 必须注意）

### 1. `ungrouped_concepts` 桶（新增，8-02 加入）
- 部分概念**挂在学派下但未细分到学者**（如"冲突理论"学派下 38 条、现代其他学者 28 条）
- 存储位置：学派节点 `scholars` 同级，字段 `ungrouped_concepts`（概念 ID 数组）
- **前端如果只遍历 `scholars` 渲染，这些概念会"消失"** → 必须额外渲染 `ungrouped_concepts`（建议显示为"（未分学者）"桶）
- 当前共 139 条在未分学者桶

### 2. 渲染层级
```
theory:  period（时期）→ school（学派）→ scholar（学者/未分学者）→ concepts
methods: phase（阶段）→ category（类目）→ concepts
intro:   topic（主题）→ concepts
```

### 3. 时期键名带括号
taxonomy 键名是 `古典时期 (1830s-1920s)`，前端展示时可用 `键名.split(' (')[0]` 取主名 `古典时期`；点击/筛选时用完整键名。

### 4. 计数口径
- 每个学者/类目/主题的概念数 = 其 `concepts` 数组长度
- 学派总数 = 各学者 concepts 之和 + `ungrouped_concepts` 长度
- 顶层总数 = 各域所有节点概念数之和 = 1968
